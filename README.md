# WanNow

## サイト概要
### サイトテーマ
愛犬に合ったドッグランを探し、現在の利用状況や来場予定を飼い主同士で共有できるコミュニティサイト
​
### テーマを選んだ理由
私は愛犬とドッグランを利用する機会が多く、実際に訪れてみると混雑していたり、反対に愛犬をほかの犬と遊ばせるために訪れたものの、ほとんど犬がいなかったりした経験があります。

犬によって、ほかの犬とのふれあいを楽しみたい、少ない頭数の中でのびのび遊びたいなど、ドッグランでの過ごし方は異なります。しかし、実際に訪れる前に現在の利用頭数やどのような犬がいるのかを知ることは難しく、愛犬に合ったタイミングを選びにくいと感じていました。

そこで、ドッグランの現在の利用状況や来場予定を飼い主同士で共有することで、愛犬に合った環境やタイミングを選んでドッグランを利用できるサービスがあれば便利だと考え、このテーマにしました。

### ターゲットユーザ
- 愛犬の性格や好きな遊びに合った環境のドッグランを選びたい人
- ドッグランへ行く前に、現在の利用頭数やどのような犬がいるのかを知りたい人
- 初めて利用するドッグランの施設環境や利用状況を事前に確認したい人

### 主な利用シーン
- ドッグランへ行く前に、現在の利用頭数や今いる犬の情報を確認したい時
- 愛犬の性格や好きな遊びに合ったドッグランを選びたい時
- 今後ドッグランへ行く予定を登録し、他の飼い主と来場予定を共有したい時
- よく利用するドッグランの混雑状況や営業時間をすぐに確認したい時
